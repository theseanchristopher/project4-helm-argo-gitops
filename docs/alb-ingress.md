# ALB Ingress Documentation

This document explains the ALB-based ingress setup.

## Features

- ACM TLS certificate
- HTTPS redirect
- Internet-facing ALB
- IP-target mode
- Host-based routing:
  - `project4-dev.seanxtopher.com`
  - `project4-prod.seanxtopher.com`
